# SubTimer · 火影忍者手游 替身计时器（安卓）

自动识别对手替身术的白烟特效，并在游戏画面上用悬浮窗倒计时，帮你记住「对手还有几秒能替身」。

## 原理

- 通过 Android `MediaProjection`（系统录屏权限）以约 8 帧/秒抓取屏幕。
- 把画面缩放到约 1/3 分辨率，只统计角色活动区域（去掉顶部血条、底部技能栏）内「高亮度 + 低饱和度」像素占比。
- 替身术触发时会出现大面积白烟，占比短时间内突增超过动态基线 → 判定为一次替身，开始倒计时。
- 全部按比例统计、不依赖固定像素坐标，换机型 / 换分辨率不用改代码。

> 借鉴的是这类 Windows 模拟器项目「识别替身烟雾帧」的思路，但运算量极小，手机上不需要 OpenCV，纯 Kotlin 像素统计即可跑。

## 用法

1. 安装 APK，打开 App。
2. 点「① 打开悬浮窗权限」→ 系统设置里允许「显示在其他应用上层」。
3. 点「② 开始识别」→ 允许录屏（会出现系统录屏通知）。
4. 回到游戏打决斗场，悬浮窗浮在画面上。
5. 大圈 = 对手替身（自动识别 + 可点按手动记录），小圈 = 我方替身。
   - 点大圈：手动记一次对手替身
   - 点小圈：记我方替身；若刚误把「我方替身」记成对手，会自动纠正
   - 长按悬浮窗：清零
   - 拖动：换位置

## 设置

- **替身冷却（秒）**：默认 15 秒（官方资料 15 秒；早期攻略写 13 秒，可自行改）。改完重新开始识别才生效。
- **识别灵敏度**：误报多 → 调低；识别不到 → 调高。

## 局限（重要）

- 屏幕上「对手替身」和「我方替身」的白烟长得一模一样，机器无法 100% 区分。默认都记到「对手」，你替身时点一下小圈即可纠正。
- 手机上浏览器拿不到游戏画面（Chrome 安卓端不支持录屏 API），所以必须做成原生 App，没法用网页实现。
- 其他白色高亮特效（部分技能、过场白闪）理论上可能误触发，已做白屏过滤 + 2.2 秒防连击 + 动态基线抑制。
- 仅作「记忆辅助」的显示工具，不读取/不操作游戏数据，不注入、不修改游戏进程。

## 自行编译

```bash
# 需要 JDK 17 + Android SDK（compileSdk 34）
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

推送到 `main` 会自动触发 GitHub Actions 构建，并在 Releases 里生成 `SubTimer.apk`。
